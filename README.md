# MPC Pad — этап 3: запись, редактор семплов, chop

Сэмплер в стиле Akai MPC для Android (Kotlin + Jetpack Compose, звуковой движок на C++/Oboe).

**Есть:** 64 пада (4 банка × 16), менеджер голосов, запись с микрофона и **внутреннего звука**
(например YouTube), waveform с маркерами, обрезка, normalize, fade, reverse, обрезка тишины,
chop (авто по атакам / поровну / вручную), назначение на пады, импорт WAV/MP3/OGG/FLAC, undo.
**Ещё нет:** секвенсор, эффекты, проекты, экспорт (этапы 4–5).

## Как собрать и запустить
1. **Android Studio** (Koala 2024.1+): *File → Open* → папка проекта. Студия сама скачает Gradle 8.9,
   предложит поставить **NDK** и **CMake 3.22.1** (SDK Manager → SDK Tools) — согласитесь.
2. Подключите телефон с **Android 10+** (отладка по USB включена) и запустите конфигурацию `app`.
3. Либо из терминала: `./gradlew assembleDebug`, затем `adb install app/build/outputs/apk/debug/app-debug.apk`
   (нужны `ANDROID_HOME` и установленный NDK).

## Что проверить на телефоне
**Микрофон.** SAMPLE → «Микрофон» → REC → скажите/хлопните → STOP. Появится waveform.
Потяните маркеры (двигается ближайший), «Обрезать», «Нормализ.», затем «→ пад A1». Режим PAD → тап по паду 1.

**Внутренний звук.** «Внутр. звук» → REC → подтвердите системный диалог → переключитесь в YouTube,
запустите музыку → вернитесь (или нажмите «Стоп» в уведомлении) → STOP. Если несколько секунд идёт
цифровая тишина, приложение покажет предупреждение: источник мог запретить захват (DRM и т. п.).

**Порог.** Включите «Порог», выставьте уровень — запись стартует сама, когда звук громче порога
(перед срабатыванием сохраняются 50 мс, чтобы не потерять атаку). «Отсчёт 3 с» — задержка перед стартом.

**Chop.** Запишите/загрузите луп → «Авто» (по атакам) или «÷8» → «Срезы → A1…» разложит куски по падам банка.
В режиме «Маркеры +» тап по waveform ставит маркер, тап рядом с маркером — удаляет.

**Файлы.** «Импорт» открывает системный выбор файла. «Записи» — последние записи (хранятся в приложении;
запись, прерванная крашем, тоже восстанавливается).

**Сохранение.** Назначенные на пады семплы сохраняются и возвращаются после перезапуска.
Параметры падов (громкость, pitch и т. д.) пока не сохраняются — это этап 5 (проекты).

## Тесты
Нативный код (WAV, обработка семплов, голоса) проверяется на обычном компьютере, без Android:
```
cmake -S native-tests -B build-tests
cmake --build build-tests -j
./build-tests/mpc_tests
```
Нужен интернет (CMake скачает GoogleTest); без сети: `-DMPC_MINI_GTEST=ON`.
Санитайзеры: `-DMPC_SANITIZE=address,undefined` или `-DMPC_SANITIZE=thread`. Сейчас 44 теста.

## Устройство
```
UI (Compose) ── команды ──► SPSC-очередь ──► аудио-callback (Oboe) → EngineCore → VoicePool → Voice
CaptureService (foreground) ── Recorder ── AudioRecord (микрофон / AudioPlaybackCapture) ──► WAV на диск
SampleViewModel ── SampleOps (C++: peaks, normalize, fade, reverse, транзиенты, WAV) ──► loadSample(pad)
```
- Запись идёт потоком на диск (заголовок дописывается в конце, парсер читает и недописанные файлы).
- Внутренний звук: сначала foreground-сервис с типом `mediaProjection`, потом `getMediaProjection`
  (требование Android 14+); согласие запрашивается на каждую запись. Собственные пады приложения из
  захвата исключены (нет обратной связи).
- Тайминг и воспроизведение — только в нативном callback, без аллокаций и блокировок.

## Известные ограничения этапа 3
- Android-часть (Kotlin UI, сервис, декодер) в среде разработки не компилировалась: нет Android SDK.
  Проверены нативный код (44 теста, ASan/UBSan/TSan), чисто-JVM части и синтаксис всего Kotlin.
  Мелкие ошибки сборки при первом запуске возможны — пришлите лог.
- Отсчёт перед записью беззвучный (метроном появится вместе с секвенсором).
- Захват внутреннего звука не работает для приложений с запретом (DRM, `allowAudioPlaybackCapture=false`).
- Максимум 10 минут записи; импорт обрезается до 120 с; предпрослушивание — до 30 с.
- Waveform без зума и playhead; назначение на пад не отменяется кнопкой Undo (она отменяет правки семпла).
- Hilt не подключён (на этом этапе обходимся ViewModel и синглтонами).

## Версия 0.4 (этап 4 + новый интерфейс IS-1)

**Что нового**
- Дизайн «железа»: алюминиевая панель, LCD (трек, волна, `SAMPLE: имя`), 7 ручек (VOL, PAN, PITCH, START, END, ATK, REL), 5 фейдеров (MAIN, TEMPO, CLICK, GAIN, TRIM), логотипы SALYCH MUSIC и IS-1.
- **Запись в пад удержанием**: нажмите `SAMPLE` (загорится красный светодиод), выберите источник `SRC:MIC/INT`, затем *удерживайте пад* — пока палец на паде, идёт запись; отпустили — семпл на паде (тишина в начале/конце срезается автоматически: `T-HEAD`, `T-TAIL`, порог — фейдер TRIM).
- **Секвенсор**: PLAY/STOP/REC, метроном (`METRO`: выкл / только при записи / всегда), отсчёт (`COUNT`), квантизация (`QUANT`: 1/4…1/32, триоли), TAP-темп, длина паттерна 1–4 такта (`LEN`), 64 паттерна (режим `SEQ`: пад = паттерн), пошаговый ввод (`STEP`, страницы `PAGE`, выбор звука `SOUND`), `ERASE`, `CLEAR`.
- **Импорт** WAV, AIFF/AIFC, MP3, FLAC, OGG, AAC/M4A и др. (кнопка `IMPORT` — прямо на выбранный пад, `EDIT` → редактор — в редактор).
- Редактор семпла (waveform, маркеры, chop) открывается кнопкой `EDIT`.

**Ограничения**
- Kotlin/Compose в песочнице не компилировался — только проверка синтаксиса; нужна сборка в Android Studio.
- Внутренний звук: DRM-приложения могут запрещать захват.
- Swing, note repeat, проекты, эффекты, экспорт, SONG, MIDI — этап 5.
- Параметры падов (ручки) не сохраняются между запусками.
